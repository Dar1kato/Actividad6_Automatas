## Reproducción

1. Clonar el Repositorio.
2. Sincronizar el proyecto con `uv sync`
3. Correr notebook o main con `uv run <nombre_del_archivo.py>`

> Nota: "notebook.py" contiene las implementaciones del AFD y AFND individuales, mientras que "main.py" es la implementación final con FastAPI.
